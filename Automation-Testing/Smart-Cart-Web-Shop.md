# Smart Cart Web Shop - Automation Testing Project

## Project Overview

Smart Cart Web Shop is an e-commerce application automated using Selenium WebDriver with Java and TestNG.

## Technologies & Tools

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Data-Driven Testing
- Apache POI
- Excel
- Git & GitHub

## Modules Automated

- Registration
- Login
- Product Search
- Shopping Cart
- Wishlist
- Checkout

## Automation Framework

The project uses:

- Selenium WebDriver for browser automation
- Java for programming
- TestNG for test execution
- Maven for dependency management
- Page Object Model for maintaining page classes
- Apache POI for reading test data from Excel

## Automation Activities

- Created automated test scripts
- Created reusable page classes using POM
- Implemented TestNG test cases
- Used explicit waits
- Used data-driven testing
- Validated expected and actual results
- Executed regression test cases
- Generated test execution results

## Project Objective

The objective of this project is to automate important e-commerce workflows and reduce repetitive manual testing effort.
