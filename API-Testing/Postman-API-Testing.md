# API Testing Using Postman

## Project Overview

Performed REST API testing using Postman to validate API functionality, response status codes, response data, and error handling.

## API Methods Tested

- GET
- POST
- PUT
- PATCH
- DELETE

## Testing Activities

- Sent API requests using Postman
- Validated HTTP status codes
- Validated JSON response data
- Checked response time
- Verified request and response parameters
- Tested positive and negative scenarios
- Tested API error responses
- Used Postman collections for organizing requests

## HTTP Status Codes

| Status Code | Meaning |
|---|---|
| 200 | OK |
| 201 | Created |
| 400 | Bad Request |
| 401 | Unauthorized |
| 404 | Not Found |
| 500 | Internal Server Error |

## Sample Test Scenarios

### GET Request
Verify that the API returns the expected response and status code 200.

### POST Request
Verify that a new record is created successfully and status code 201 is returned.

### PUT Request
Verify that an existing record is updated successfully.

### DELETE Request
Verify that the selected record is deleted successfully.

Postman
